请根据标准 rm_schema 和候选回答 candidate，输出结构化语义评分。

【最终输出格式】
严格只输出如下 JSON，不输出解释：
{"c":[0.0],"lat":0.0,"lon":0.0,"q":0.0,"x":0.0}

【字段含义】
c：factor coverage，list长度必须等于标准JSON中的因素数量，顺序一致。
lat：横向动作评分。
lon：纵向动作 + 行为目标评分。
q：表达质量评分。
x：冲突 / 幻觉惩罚。

【核心原则】
评分前必须逐 factor 对齐，但最终不输出对齐过程。
每个 factor 必须独立评分，禁止跨因素借分，禁止整体语义补偿。
每个 factor 必须绑定判断：位置 + 事件类型 + 具体描述。
不得因为动作正确、其他factor正确、整体场景相似，而提高某个factor得分。

【c评分规则】
1.0 = 位置正确 + 事件类型正确 + 具体描述正确。
0.5 = 位置正确 + 事件类型正确，但具体描述缺失、泛化，或同类子类型错误。
0.0 = 未覆盖、位置错误、事件类型错误、动态/静态属性错误、完全语义错误、factor mixing。
candidate只提到某个factor时，其他未提到factor必须为0。
若具体描述相同但位置不同，不能匹配该factor。
若把一个factor的具体描述放到另一个factor的位置上，属于factor mixing，相关factor均为0。

【位置规则】
方向泛化允许0.5，例如“左前方”写成“前方”。
方向错误必须0.0，例如“左前方”写成“右前方”。
若标准位置为“前方”，candidate写成“左前方/右前方”，一般视为位置偏移，记0.0，除非上下文明确只是轻微泛化。

【静态障碍 vs 动态目标】
静态障碍类：事件类型通常为“障碍”，核心是占道、停靠、阻挡、静态空间阻塞。
包括：锥桶占道、事故车占道、静态障碍物、行人占道、两轮骑行者占道、三轮骑行者占道、公交车占道、工程车占道、施工区域占道、车辆停靠。
动态目标类：事件类型通常为“动态目标”，核心是运动趋势、交互行为、时序变化。
包括：车辆缓慢行驶、对向车辆逆行、车辆掉头、车辆倒车、车辆切入、紧急切入、行人通行、行人横穿、两轮骑行者缓速、两轮骑行者切入、三轮骑行者缓行。
必须严格区分：车辆停靠≠车辆缓慢行驶；车辆倒车≠车辆掉头；逆向行驶≠正常缓行；行人占道≠行人通行；两轮骑行者占道≠两轮骑行者缓速；静态障碍≠动态目标。

【静态障碍子类型规则】
对于“障碍/占道/阻挡/停靠”类factor：
位置正确 + 事件类型正确 + 具体障碍物完全一致：1.0。
位置正确 + 事件类型正确 + 同属静态障碍占道，但具体障碍物实体不同：0.5。
例如：事故车占道→锥桶占道；事故车占道→施工区域占道；锥桶占道→静态障碍物占道。
位置正确 + 事件类型正确 + 只泛化为“障碍物占道”：0.5。
位置正确，但把静态障碍写成动态目标：0.0。
例如：事故车占道→事故车缓慢行驶；车辆停靠→车辆缓慢行驶；行人占道→行人横穿。

【动态目标规则】
动态目标必须保持运动趋势、行为方向、时序含义。
“车辆逆向龟速行驶”写成“车辆逆向行驶”：0.5。
“车辆逆向龟速行驶”写成“车辆缓慢行驶”：0.0。
“车辆切入”写成“车辆变道”：0.5。
“车辆切入”写成“车辆正常行驶”：0.0。

【lat评分规则】
1.0 = 横向动作正确。
0.5 = 部分匹配。
0.0 = 错误或冲突。
若横向为空，默认保持。
保持 / 左变道 / 右变道 / 左避障 / 右避障 是不同动作，方向错误必须0.0。
“向右变更车道”与“右变道”等价。
“向左避障”与“左避障”等价。
“变道”和“避障”不是完全等价：若标准是右变道，候选写右避障，可给0.5；若方向相反，给0.0。

【lon评分规则】
1.0 = 纵向动作和行为目标正确。
0.5 = 部分匹配。
0.0 = 错误或冲突。
若纵向为空，默认匀速。
加速 / 减速 / 匀速 / 停车 是不同动作。
若标准纵向为空，candidate新增“减速避让”，通常lon=0.5，x=0.5。
若标准纵向为空，candidate新增“停车等待”，通常lon=0.0，x=0.5。
行为目标需区分：避让 / 绕行避让 / 让行 / 通行 / 停车等待。

【q评分规则】
1.0 = 自然清晰。
0.5 = 可理解但表达一般。
0.0 = 关键词堆砌、模板化、重复、难理解。

【x冲突/幻觉规则】
0.0 = 无明显冲突。
0.5 = 轻微冲突。
1.0 = 严重冲突。
若candidate引入rm_schema中不存在的关键语义，则记x，包括新的交通参与者、新障碍、新风险、新交通信号、新约束、新动作意图、factor mixing。
若candidate用错误实体替换标准实体，例如事故车占道→锥桶占道、行人占道→两轮骑行者占道、车辆停靠→工程车占道，即使c可给0.5，也应x=0.5。
若candidate引入相反交通状态、危险动作、错误通行条件、错误信号灯，通常x=1.0。
普通修饰词不算conflict，例如颜色、程度副词、轻微描述扩展。
